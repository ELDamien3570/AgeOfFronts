# Russian Early Modern truck

WWII Soviet ZiS-5-inspired covered cargo trader. Strict overhead, screen-down. Original imagegen source and full prompt remain in SourceArt and Generation-Manifest.json. This is a model-inspired game interpretation rather than an exact technical reconstruction.

Idle and Travel each have ten 512 px frames in 2560 x 1024 RGBA sheets. Edge-on tire tread scrolls without changing wheel silhouettes; cab and load use restrained local vibration. Moving road preview is inspection-only. Rebuild with `python build-animations.py --age EarlyModern`. Editable regions: rig-authoring.json. Prior art and gameplay remain unchanged.
