# Russian civilization: Modern buildings

Seventeen draft building icons cover the full current Modern roster, using mixed
Soviet-era brick/concrete industry and contemporary Russian facilities. The strict
overhead camera, large equipment and different site layouts prioritize role clarity.
The regional source boundary is documented in Regional_References.md.

Modern uses the live Depot and Arms Factory identities. Stables, Blacksmith,
Armory and Tower are unavailable at this age. The old Modern Stables artwork
already depicts a vehicle facility and remains the Depot comparison image.
Gun Nest and Trench compare against existing base terrain-kit art. Missile Defence
has no equivalent base building inspection image, so its comparison shows only
the Russian draft. No new gameplay building IDs are invented.

The selected Icon.png files match their selected versioned SourceArt masters.
All 28 generated masters are retained, including the rejected earlier gun-nest
versions, a fresh Soviet DShK rebuild and its overhead camera refinement. Generation.json records exact full prompts, references, generated
output paths, selected versions and revision reasons. Art was generated and
edited through the built-in image_gen tool.

Approved_Art_Baseline.json records all 59 approved earlier-age images.
Source_Validation.json checks their preservation, selected-master parity,
transparent alpha and solid-content containment. Browser_Validation.json and
inspection PNGs record local review, small previews and culture/age/role filters.

The existing declarative culture manifest exposes this set in the building
inspection page. Base art remains in its original folders. These static source
icons are drafts for user review. The Trench icon is a representative inspection
footprint; connected terrain tiles, directional kits, animations, runtime culture
selection and publication remain separate work.
