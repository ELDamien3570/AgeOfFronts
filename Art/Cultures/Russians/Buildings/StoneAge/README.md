# Russian civilization: Stone Age buildings

All nine selected images were approved by the user on October 2, 2026.
`Approval.json` records the approved masters and their file hashes.

Separate source artwork for the Russian culture. The existing shared building
art remains in place while this set is created, reviewed, and prepared for release.

Art direction: prehistoric forest settlements using timber, thatch, earth, hides,
and subtle regional character. These are game designs, not reconstructions of a
historical Russian civilization in the Stone Age.

Each building has its own folder. Keep generated masters and earlier iterations
in `SourceArt/`; the selected review image is `Icon.png`. Record prompts and image
provenance in `Generation.json`. The building manifest in the parent folder
lists the selected artwork. Runtime preparation and culture selection are a
separate integration step; this folder does not change gameplay or unlocks.

| Folder | Existing gameplay role |
| --- | --- |
| City | Population / reserve growth |
| Barracks | Infantry recruitment |
| Archery Range | Ranged recruitment |
| Stables | Cavalry recruitment and horse production |
| Factory | Trade goods and gold income |
| Port | Naval recruitment and maritime trade |
| Mine | Resource extraction |
| Siege Workshop | Siege equipment and recruitment |
| Tower | Ground defense |

All images use a directly overhead camera, genuine transparent margins, and
distinct footprints and visible work areas. Inspect role clarity at small sizes
as well as the full source resolution.
