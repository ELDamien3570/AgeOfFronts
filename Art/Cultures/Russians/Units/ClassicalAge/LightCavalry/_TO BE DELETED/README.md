# Russian Classical Age Light Cavalry

Nine six-frame animations derived from the Bronze Age mounted spearman motion sheets and the approved iron idle: idle, walk, spear thrust, hit, charge impact, gallop, charge thrust, together fall, and thrown rider. Hammered iron replaces the bronze helmet, pauldrons, bracers, spearhead and metal fittings. Leather, fur, spear grip, chestnut horse and overhead composition remain consistent. No shield; the free hand holds reins.

`Idle-v1.png` preserves the native built-in ImageGen RGBA output. `Generation.json` retains the complete edit prompt, reference and source. `animations.json` registers fixed saddle roots, timings, impact markers and source frame order for solo previews. `Validation.json` checks all 54 distinct frames, transparent edge guards, preview bounds and approved-idle preservation. Native atlases and prompts are preserved in `SourceArt`; the editable composition recipe uses one common scale with authored row gutters and no painted pixels. The together-fall correction restores natural horse ears and brown leather tack; the earlier atlas remains archived. The review includes 32, 48 and 64 px previews.

The idle design is approved; animation acceptance is pending user visual review. Bronze cavalry and base art are preserved; this is artwork only, without gameplay integration.
