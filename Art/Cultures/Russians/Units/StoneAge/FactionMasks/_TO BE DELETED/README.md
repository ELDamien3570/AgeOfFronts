# Russian Stone Age faction masks

Review: Review.html (serve Art on localhost, then open /Cultures/Russians/Units/StoneAge/FactionMasks/Review.html). The page offers troop, authoring/runtime sheet, motion, faction color, preview-size and frame controls. StoneAge-Color-Review.png is the static comparison; each troop/dataset has Motion-Review.png for every frame.

Coverage: Clubman, Javelinist, MountedSpearman and Scout. Each has nine selected authoring sheets from its current animations.json (36 masks, 216 frames). Clubman, Javelinist and MountedSpearman also have four runtime sheets each (12 masks, 72 frames). Scout has no runtime set in the current checkout; no new gameplay assets were invented. Source and runtime masks use their respective native dimensions and frame layout, and are not interchangeable.

Selection: primary red fabric in cap, sleeves and tunic. Fur, neutral trousers, skin, leather belts/cuffs/boots, weapons, and horse anatomy are excluded. The user explicitly requested inclusion of the Mounted Spearman's exposed red saddle panel. That panel is included. The Scout's neutral saddle remains unchanged.

Encoding: 8-bit grayscale coverage, 0 = preserve the original pixel, 255 = full fabric chroma replacement. Intermediate values blend boundary coverage. Preserve the original sprite alpha separately; mask coverage is not opacity. Keep shading/value from the original fabric. Preview color recipes and the corresponding browser implementation are in build-masks.cjs and Review.html. The darkest garment seams and outlines intentionally remain unchanged.

Original source artwork, runtime artwork, animation manifests and gameplay code are untouched. Masks, recolored example sheets, review assets, the reproducible script and Validation.json are additive. This age awaits user artistic review before proceeding to Bronze Age or renderer integration.

Build: run Node on build-masks.cjs. The script defaults to the bundled Sharp library on this machine; STONE_MASK_IMAGE_LIB may override its module path. It follows current manifests rather than enumerating obsolete art versions. Material selection is explicitly calibrated for these Stone Age troops, not a universal fabric detector for other ages. Native source boundaries are refined from source chroma gated by isolated fabric panels at tactical scale; this avoids a source-scale connection between red cuff/skin shadows and cloth. Runtime masks are authored at native tactical scale.

Built-in ImageGen produced initial semantic reference stencils for Javelinist, Mounted Spearman and Scout; the Clubman reference remains with its earlier prototype. The prompt requested white primary red cap, sleeves and tunic regions and black fur, neutral trousers, skin, leather, weapons, horse and background, preserving the exact 3x2 sheet. Generated references have approximate contours and some off-target marks (notably on javelins), so Guides/ files are archived references only and are not the delivered masks. Final PNG masks are source-aligned local refinements.

Validation: native mask dimensions, no coverage on alpha-zero source pixels, unchanged preview alpha, byte-identical unmasked preview pixels, and original source file SHA-256 checks. Visual inspection covered all original/blue frame comparisons and idle blue/green/purple/white comparisons. Review page JavaScript syntax and HTTP serving were checked. Browser automation could not start because of the Windows sandbox setup failure, so no completed browser-interaction check is claimed. This does not establish in-game rendering or artistic acceptance.
