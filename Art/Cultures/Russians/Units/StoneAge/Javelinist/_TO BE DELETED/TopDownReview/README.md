# Russian Stone Age javelinist overhead revision

The approved steeper idle is Idle-TopDown-v3.png. This review develops a complete solo animation set from that camera, preserving the original javelinist assets and previous overhead idle drafts.

Overarm throws end empty-handed. Reload is a separate clip that retrieves a new javelin from the back pouch. The charge loop uses the alternating movement poses at a faster cadence. Side and backward deaths are separate variants.

Native sources and prompts live in ../SourceArt/TopDown-Animation-Generation.json; editable registration lives in ../SourceArt/TopDown-Composition.json. Rebuild with ../SourceArt/compose_topdown_animations.py. Do not rerun prepare_topdown_review.py over animation metadata.

Validation.json records static frame bounds, transparency and native cell boundary checks. Browser playback and user visual approval are separate from these checks. Runtime formations, projectiles and integration remain outside this art review.
