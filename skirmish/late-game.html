Late-game skirmish lab

Start directly in a saved late-game world. The playable replay uses the ordinary game worker, renderer, controls and HUD. Performance timings appear alongside the game.

  • Play the 30-minute Migration replay
    About 530 squads and 270 ships. Takes control of one surviving nation so orders can be tested. Restart returns to the same checkpoint.
  • Measure the original replay without rendering
    600 ticks at the ordinary 20-tick cadence, with simulation, encoding and decoding measured separately.

Keep the test tab in the foreground and run one match at a time. “Save performance report” exports the current timings. Command admission measures input reaching the worker; route execution may take longer.

Generate another playable Migration replay from a captured checkpoint:

node node_modules/tsx/dist/cli.mjs scripts/createLateGameReplay.ts checkpoint.v8 out/replay.json 3

The final number selects a surviving nation with field squads. Load it with /skirmish/index.html?diagnostics&replay=/out/replay.json. These local fixtures are not bundled into public releases.
