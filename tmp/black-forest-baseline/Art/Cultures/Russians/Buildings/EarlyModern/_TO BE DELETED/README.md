# Russian civilization: Early Modern buildings

WWII and mid-twentieth-century Soviet building art for the eight-age inspection taxonomy. Eighteen icons are available: the existing Military Airstrip plus seventeen new drafts. The previous nineteenth-century set remains in ../Napoleonic. This taxonomy is art-only and does not change playable age progression.

All additions are drafts pending visual approval. The airstrip authored separately is preserved unchanged. Base buildings, walls and gates remain available; no Russian wall or gate kit was generated.

Versioned SourceArt masters are retained. No runtime building entity or technology-to-building binding was added.
